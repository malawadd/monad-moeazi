# Calibrated Shadow/TCA fixture plane

Feature 33 is an isolated Test Center research simulator over checked-in synthetic CLOB and Arbitrum AMM facts. It evaluates fill ranges, lifecycle conservation, complete-or-unknown costs, a frozen immediate-quote baseline, and synthetic-only calibration status.

It consumes an explicitly selected same-operator Feature 32 fixture run as `requires_revalidation`; it transfers neither authority nor identity. The test plane has no product Shadow, proposal, route, venue, gateway, provider, wallet, signer, broadcast, network, Convex, Temporal, or customer-mode path.

Missing, stale, proxy, gapped, incomplete-cost, or invalid predecessor facts become unknown or unscorable. A synthetic cohort always remains `research_only`: certified actual count is zero and no local result can promote or authorize anything.
