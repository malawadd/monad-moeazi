# Capability and Delegation Lifecycle Ledger

Feature 08 is a local-only capability fixture ledger. It evaluates a frozen synthetic
grant ancestry, observations, lifecycle history and exact action using immutable
Timescale records. It is not a wallet, signer, delegation executor, revocation
adapter, gateway decision, provider/RPC client, or product capability service.

Only the isolated Test Center can run the checked-in corpus. The feature defaults off;
`observe` and isolated `enforce` retain Manual Guard and Lite Mode and cannot change
customer mode, product routing, native authority, signing, broadcasting, or any
external state. Feature 05 and 06 Test Center controls are prerequisites only and
cannot make an action executable outside this fixture surface.

Missing, stale, disputed or malformed evidence returns a conservative decision. A
local dispatch latch can express pending revocation but never proves it: only a future
approved native post-state owner may establish verified revocation. Rollback disables
the lease and preserves immutable history.

Activation requires separately approved Particle/Magic and native permission owners,
finalized Arbitrum evidence, Permit2/venue adapters, production custody, gateway and
sidecar revalidation, independent review, funded validation and operational drills.
