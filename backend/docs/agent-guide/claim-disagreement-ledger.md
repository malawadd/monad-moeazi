# Claim disagreement ledger

Feature 28 is a local, fixture-only Test Center evaluator. It validates checked-in
typed claims, groups exact comparable claims, identifies material contradictions,
and records a hypothetical bounded escalation route. It has no product, provider,
model, Convex, Temporal, signer, wallet, venue, or execution integration.

The required Feature 25 Evidence Event Fabric selection is explicit and remains
`requires_revalidation`; it cannot contribute truth or authority. `observe` records
the synthetic comparison. `enforce` can only abstain inside the isolated Test Center.
Disable the feature to return to the conservative unavailable/off behavior.

Results are research-only: synthetic labels are not human adjudication and no claimed
benefit has been established. Activation requires chronological adjudicated evidence,
power analysis, provider-cost approval, tier non-inferiority, product schema/prompt
review, and separate approval.
