# Customer account portability

Feature 24 is a local-only Test Center fixture proof, not a customer export service.
It evaluates checked-in synthetic records for ten registry-owned domains, preserving one
native cutoff per domain and persisting only append-only metadata, hashes, counts and
receipts in Timescale/Postgres. Virtual JSON/CSV/schema/README bytes exist only in
bounded memory and are cleared before the aggregate-only projection is returned.

Product portability, authenticated customer step-up, authoritative Convex/Timescale
adapters, legal/privacy review, Usage Rights authorization, encrypted staging, object
storage, egress, email, download URLs, and delivery remain unavailable. The Feature 03
selection is prerequisite context marked `requires_revalidation`, never export authority.
Observe computes `would_issue`; isolated enforce can model single-use grant consumption,
expiry/revocation and cleanup without a bearer, URL, file, provider, network action, or
customer-state change.

Do not add a raw dump, archive, external delivery, unbounded cursor, persistent package
bytes, customer PII, credentials, hidden reasoning, or a product route. Rollback turns
the Feature 24 Test Center control off and freezes new fixture bundles while retaining
immutable history and conflicts.
