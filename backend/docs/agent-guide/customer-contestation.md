# Customer contestation fixture

Feature 23 is an isolated local Test Center proof of a synthetic case lifecycle,
evidence references, finding, response, appeal, correction, and non-executing remedy
receipts. It accepts only checked-in scenario IDs and an explicitly selected,
same-operator Feature 20 run as `requires_revalidation` context.

It is not a customer-support, identity, legal, communication, policy, evidence, or
remedy service. It has no Convex current-state mutation, Temporal workflow, Redis
case truth, attachments, external delivery, provider, signer, wallet, venue, or
execution path. The result always reports product outcome unavailable, no authority
effect, no operation performed, zero external attempts, and zero provider cost.

Timescale/Postgres records local append-only fixture bundles only. A missed delivery,
pending appeal, unresolved correction, uncertain remedy, stale/disputed evidence, or
invalid lifecycle holds or blocks closure. Production activation requires separately
approved policy/privacy/retention owners, qualified human investigators and genuinely
independent appeal reviewers, authoritative state/evidence integrations, a separately
authorized remedy service, and an explicit activation review. Expected cost is unknown.
