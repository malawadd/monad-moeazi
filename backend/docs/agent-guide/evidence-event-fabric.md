# Evidence Event Fabric

Feature 25 is a default-off, loopback-only Test Center fixture proof. It folds only checked-in synthetic events into immutable local graph metadata and safe aggregates. It has no source adapter, provider, network path, product projection, Temporal start, signer, wallet, venue, or execution authority.

Observe and isolated enforce require an explicit same-operator Feature 03 selection. Enforce rejects invalid fixture transitions before local persistence; it never enables product enforcement. All projections retain `productOutcome=unavailable`, `runtimeDispatch=unavailable`, and zero external attempts/cost.

The live-validation plan remains gated: authoritative adapters/rights, lifecycle owners, separately approved metered validation, durable dispatch, powered SLO cohorts, and activation approval are all required before any promotion.
