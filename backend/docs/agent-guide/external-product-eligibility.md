# External product eligibility

Feature 22 is a local, checked-in synthetic Test Center evaluator. It accepts no
law, KYC, sanctions, source or customer input from callers, and it never calls a
provider, product route, signer, wallet, venue, network or execution path. A result
is fixture-only, not legal advice, and cannot grant product eligibility or authority.

It requires an explicitly selected same-operator Feature 21 run only as
`requires_revalidation` non-authorizing context. Qualified ownership, reliable source
currency, legal/KYC/sanctions conclusions, product enforcement and execution remain
unavailable.
