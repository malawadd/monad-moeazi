# External usage rights

Feature 21 is an isolated Test Center fixture evaluator for one exact synthetic data
operation. It stores only typed metadata hashes and safe aggregate results. A fixture
result is not legal advice and does not establish a license, compliance, provider
safety, execution authority, or product permission.

The evaluator accepts only checked-in scenarios. It uses literal Arbitrum chain 42161,
strict canonical hashes, exact operation matching, bounded leaf lineage and the
conservative order deny, manual legal review, unknown, then allow. An allow with any
release obligation remains pending until matching synthetic receipts close it.

Feature 03 may be frozen as same-operator `requires_revalidation` context only; it
never decides rights. Product/runtime enforcement, qualified legal or commercial
ownership, source currency, Convex projection, Temporal obligation handling, Redis
decision caching, downstream consumers, providers, wallets, signers, venues and all
external actions remain unavailable.

Rollback turns the local feature control off and removes UI exposure while preserving
the additive migration and immutable fixture evidence. Never down-migrate or rewrite
historical decisions.
