# Incident Communication Outbox

Feature 15 is an isolated Test Center fixture/replay proof. It creates deterministic,
customer-safe `in_app` communication intents and separate simulated display,
acknowledgement, supersession, dead-letter, and escalation receipts. It is default-off
and has no Convex projection, Temporal workflow, external provider, email, SMS, push,
webhook, signer, wallet, execution, or product authority.

Acknowledgement is a communication receipt only. It never changes incident state,
containment, recovery, approval, customer mode, or authority. External channels are
prohibited and their cost is unknown pending a separately authorized activation.
