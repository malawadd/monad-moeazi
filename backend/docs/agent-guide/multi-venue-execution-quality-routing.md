# Multi-venue execution-quality routing

Feature 32 is an isolated Test Center research evaluator. It compares checked-in,
exact-integer quote and book fixtures after an explicitly selected Feature 31 sizing
fixture. It does not invoke the existing routing service, a venue, signer, wallet,
provider, gateway, sidecar, Convex, Temporal, or network endpoint.

Only a same-operator, non-authorizing Feature 31 run may be selected. The binding is
always `requires_revalidation`; it transfers no identity, authority, source class,
or readiness claim. Missing, stale, gapped, indicative, unhealthy, unreconciled, or
uncertain fixture evidence excludes a route or returns an abstention.

The existing `RoutingService` remains the sole product router. Product routing and
execution are unavailable. Any convergence requires separately approved authoritative
owners, certified channel evidence, Shadow validation, and an activation review.
