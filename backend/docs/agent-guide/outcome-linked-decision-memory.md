# Outcome-linked decision memory

Feature 35 is an isolated Test Center research fixture. It joins checked-in synthetic
decision episodes to append-only synthetic outcome revisions, computes deterministic
maturity and fixed-point scores, and returns a bounded inspection bundle.

It is not product memory, chat memory, prompt mutation, scheduling, routing, or an
outcome source of truth. Feature 25 is selected explicitly per same operator and is
always `requires_revalidation`. No provider, network, workflow, signer, wallet, venue,
credit, or execution attempt is permitted. Redis remains limited to the existing
expiring Test Center control lease; fixture history belongs only to local Timescale.
