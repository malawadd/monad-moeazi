# Portfolio-aware sizing

Feature 31 is a default-off, local-only Test Center experiment. It consumes only
checked-in synthetic portfolio and market facts, binds one same-operator Feature 09
fixture run as `requires_revalidation`, and emits an inert sizing result. It does not
change proposals, approvals, policy, routing, execution, signers, providers, venues,
or product state.

Missing, stale, disputed, unreconciled, mismatched-scope, or emergency inputs abstain.
Observe records a would-decision only; isolated enforce can create only synthetic
append-only fixture history. Neither can grant product authority.

Product integration requires authoritative portfolio/reconciliation/market owners,
certified protective exits, chronological replay and Shadow validation, then a separate
approval. The research benefit remains unproven.
