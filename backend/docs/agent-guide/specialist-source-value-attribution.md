# Specialist source-value attribution

Feature 29 is a local, fixture-only Test Center proof. It keeps supplied, cited and
supporting evidence identities separate, evaluates closed role contracts, and reports
finite paired source-family ablations as conditional—not causal—research. It never
calls providers, changes Pro/Max, removes a source, gates a product role, or changes
product authority. Both Feature 25 and Feature 28 run selections are same-operator,
`requires_revalidation` context only. Product evidence gating is unavailable.
