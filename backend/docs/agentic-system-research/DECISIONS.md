# Candidate Decision Log

This log records candidates that were held, rejected, or materially reframed. Approved
features are indexed in the program [README](./README.md).

## Decision meanings

- **Approved:** score `75–100`, no hard-gate failure, and a feature dossier exists.
- **Hold:** score `60–74`, or evidence/prerequisites limit work to Evaluation Lab.
- **Rejected:** score below `60` or a hard-gate failure.
- **Reframed:** the original proposal is not approved; a materially different proposal
  is evaluated separately.
