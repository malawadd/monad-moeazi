# Source Registry

## Classification

- **Production documentation:** documents an implemented product or SDK. It proves an
  interface or architecture exists, not that it improves trading performance.
- **Research/backtest:** paper or research repository evaluated on historical or
  simulated data. It supports a mechanism hypothesis, not live crypto alpha.
- **Platform claim:** vendor-authored capability or performance statement that needs
  independent verification.
- **Unimoazi evidence:** current repository code, tests, and project guides.

All web sources were last checked on 2026-08-05 unless another date is recorded.
