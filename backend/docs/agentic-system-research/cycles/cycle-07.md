## Useful folded lessons

- An account-scoped exact-intent duplicate can collapse idempotently, but approved,
  executing, submitted, or uncertain work is immutable to the coherence gate. Opposing
  work holds and reruns sizing; `net_candidate` is never an order/cancel instruction.
- Gate, sizing, policy, and calibration owners may emit non-authorizing boundary
  fragments. No global engine searches for cap/policy/market changes or recommends
  weakening a constraint.
- An analytical run manifest separates configured, provider-declared, observed, and
  unavailable identity and hashes retained artifacts. It cannot attest which hidden
  model an opaque provider ran or promise deterministic output.

## Rejected variants

- Cross-account/tenant netting, LLM proposal arbitration, or cancellation of approved/
  submitted/uncertain work.
- Model-generated what-if advice, arbitrary parameter search, cap-loosening suggestions,
  causal claims, or explanation output used as execution input.
- A second provenance service, provider self-report relabeled as attestation, secret
  retention, provider probes, billable CI, or automatic promotion from provenance.
