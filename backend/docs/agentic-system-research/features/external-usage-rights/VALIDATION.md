# Validation and Promotion

Use local fixtures for plan downgrade, terms change, API/web, raw/derived, every
operation pair, mixed sources, attribution failure, CC variants, provider sharing,
replay, evaluation-versus-training, conflicts, expiry, tenant isolation and export.

Thresholds: 100% exact decisions or block; zero missing/expired/mismatched allow; zero
LLM legal decision; deterministic hashes; 100% mixed lineage; zero unfulfilled
mandatory release obligation. Any 20–40% review-time hypothesis needs timed repeated
cases.

Activation requires qualified rule owner and golden cases. Kill for automatic terms
scraping/interpretation, public/free means allowed, global flag, content stored before
gating, retroactive rewrite, opaque privacy/eligibility/security merge or rights
decision granting execution.

## Baseline, datasets, and sample requirements

The baseline is the current repository behavior or the same frozen plan with this
feature disabled. Datasets begin with versioned local fixtures, adversarial cases and
chronological replay that satisfies Evidence Lifecycle and Usage Rights. Deterministic
safety invariants are checked on every enumerated case, not a statistical sample. Any
percentage or quality hypothesis requires a preregistered power analysis and held-out
chronological cohort; an underpowered result is inconclusive. Promotion requires every
feature-specific threshold plus replayability and cost/latency bounds. One hard-gate or
safety-invariant breach triggers kill/demotion and preserved evidence.

## Measured local-fixture status

Local validation passed: 621 Python tests with 5 skipped, 160 Node tests, the 36-case
checked-in scenario corpus, 144 cross-operation non-reuse attempts, an evaluator p95 of
3.294 ms across 10,000 iterations, and a 25.092 ms p95 for the disposable persistence
benchmark. The migration SQL, repository harness, and clean local build also passed.

This does not promote the feature beyond the isolated Test Center. Qualified
legal/commercial ownership, authoritative agreement/plan/terms currency, independent
golden review, product pre-sink integration, product projection, durable remediation,
cache invalidation, privacy/accessibility review, and downstream activation remain
required. No legal, compliance, permission, execution, or external-use claim follows.
