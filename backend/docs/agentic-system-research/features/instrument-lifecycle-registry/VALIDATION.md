# Validation and Promotion

## Local implementation validation

The isolated Test Center runs frozen adversarial identities, aliases and lifecycle
states. It remains unavailable to product runtime until authoritative owners and a
separate activation review are approved.

Use frozen FIX/native messages and synthetic identical symbols across venues,
spot/perp and namespace collisions, token/spot ID confusion, mainnet/testnet indices,
metadata reorder, UI remap, rename without continuity, multiplier/oracle/collateral
change, split/reverse split/rebase/migration, expiry/delisting/settlement, late/conflict/
correction events and positions spanning versions.

## Thresholds

- 100% routed/proposed/risked/executed/journaled instruments reference an exact version.
- Zero symbol-only or environment-free identity passes.
- Zero unreviewed continuity transforms.
- 100% lifecycle changes invalidate affected route/risk/proposal/calibration artifacts.
- Zero new exposure under halted/reduce-only/delisting/settled/delisted/unknown/
  rebaseline-required.
- Certified applicable cancel/reduce/settle/reconcile remains available.
- Identical frozen metadata/events/version reproduce identity/decision hashes.

Measure ambiguous mappings blocked, propagation completeness, stale invalidations and
wrong-version decisions. Any 50–90% mapping-error range remains a mutation-corpus
hypothesis with a denominator.

Promote per native namespace and lifecycle class. Kill or redesign if symbols are
keys, aliases auto-merge, definitions mutate in place, indices are permanent, unknown
lifecycle permits increases, delisted history is deleted, a model decides continuity
or positions migrate automatically.

## Baseline, datasets, and sample requirements

The baseline is the current repository behavior or the same frozen plan with this
feature disabled. Datasets begin with versioned local fixtures, adversarial cases and
chronological replay that satisfies Evidence Lifecycle and Usage Rights. Deterministic
safety invariants are checked on every enumerated case, not a statistical sample. Any
percentage or quality hypothesis requires a preregistered power analysis and held-out
chronological cohort; an underpowered result is inconclusive. Promotion requires every
feature-specific threshold plus replayability and cost/latency bounds. One hard-gate or
safety-invariant breach triggers kill/demotion and preserved evidence.
