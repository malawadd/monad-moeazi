# Live validation gate

This local implementation authorizes no live activity. Activation needs authoritative
source/entity/ownership/rights/lifecycle owners, qualified security/legal/data review,
held-out chronological evidence, approved Shadow validation and a separate activation
approval. Expected provider, cloud and review cost is unknown.

Before any activation, approve the environment and budget, verify source registries and
rights, run bounded Shadow replay, monitor quarantine/cluster/correction coverage, abort
on any authority increase or unsafe-content escape, preserve sanitized evidence, and
roll back to the frozen local policy. No funded, signing, broadcast, deployment, or
external mutation step is authorized here.
