# Evidence register and scope

Research date: **30 September 2026**. This register records findings from active backend, mobile, product, operator, and authority paths.

This register distinguishes external documentation, inspected source, and local verification. Local documentation integrity checks establish artifact consistency; source inspection is bounded, not a whole-repository audit.

**D** means official documentation/metadata; **S** means selected source inspected; **L** means a named runtime verification performed locally. There is **no L verification of an upstream integration or customer journey in this research**. Local documentation integrity checks establish only artifact consistency. Source inspection is bounded, not a whole-repository security or correctness audit.

## Maintenance, costs, and remaining uncertainty

The earlier register records repository push dates and archived flags; recent HEAD availability and public releases support continued evaluation but do not prove support quality, compatibility or security. This phase did not score issue response times, reproduce upstream tests, audit every dependency, benchmark hardware or certify SDK operations. Those remain explicit qualification work, with an experiment/rejection condition in each component chapter.

No core-library OSS license makes proprietary feeds, model providers, cloud services, on-ramps or venue fees free. Self-hostable candidates are considered only with their actual required dependencies; optional commercial services are not selected by implication. Existing providers remain configured through Moeazi. Exact transitive package/image/model-weight/contract licenses must be recorded before installation/adoption.

Public-source retrieval did not use customer account credentials or call trading/provider endpoints. No SDKs were installed or run. No application test suite, migration, build, deployment, CI, model generation, account probe or funded experiment was executed. Source conflicts, failed upstream reads, unknown strategy performance and unverified limits remain labeled rather than resolved by speculation.
