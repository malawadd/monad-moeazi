Direct execution acceptance status

Three capped BTC cycles executed through Perpl's delegated account on Monad Testnet: long, short, long. Each entry and close has a finalized transaction and verified Exchange fill. A PUMP long opened automatically before the operator script and was closed; another PUMP short opened after the script and was closed by owner stop. The final 100 AUSD run returned 99.732661 AUSD, a measured loss of 0.267339 AUSD. The account has zero positions, order locks and collateral; the delegated operator is revoked. The factory enrollment gate and all funded local execution gates are off. The retained API transport remains blocked by Perpl's Origin whitelist.

How to read the predictions

Purple bars are illustrative flat-price, fee-only estimates made with a 0.0345% taker fee per side: −0.0345 AUSD for the roughly 50 AUSD PUMP position and −0.0287 AUSD per roughly 41.6 AUSD BTC cycle. They omit spread, price changes, funding and slippage. Green bars use finalized Exchange balances after each close. These estimates were not live trade signals or guaranteed returns.
