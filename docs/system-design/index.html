NATIVE APP ANATOMY

Mobile structure

React Native · Android + iOS

The signed-in app is a tab navigator inside a native stack. App context owns session and screen state; service modules carry requests and signing.

!

Current rollout boundary. Mera passkey sign-in is active. AppContext deliberately pauses chain actions and autopilot controls while the sign-in rollout is in progress, even though review screens and backend routes are present.

IMPLEMENTATION INVENTORY

Technology & ports

Local stack · loopback bindings

Host ports are for local tools and the emulator. Containers use Compose DNS and internal ports. The mobile client calls the Hono API; it does not connect directly to Convex or Python services.
